## 📌 프로젝트 소개

**Assign**은 모든 직장인의 점심시간을 지켜드립니다!

1분 1초가 소중한 당신의 점심시간! 점심 메뉴 선택까지 업무가 될 수는 없다! <br>
 당신의 팀은 오늘도 식사 메뉴 선택으로 고민하고 있나요? 오늘 뭐 먹지는 AI가 당신과 팀원들의 취향을 분석해 최적의 식사 메뉴와 회식 장소를 추천해주는 서비스입니다.
